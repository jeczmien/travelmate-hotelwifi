# Changelog

## 0.1.0 - 2026-09-03

Initial public release.

- Mobile-first Travelmate uplink management panel.
- Wi-Fi scan and uplink creation.
- Remembered-network enable/disable, password update and removal.
- Uplink priority controls.
- Wi-Fi, WireGuard and Internet status.
- Restricted rpcd account and ACL.
- Standalone PWA-style frontend under `/hotelwifi/`.
- English default language and language selector matching the current LuCI language catalogue.
- RTL support for Arabic, Persian and Hebrew.
